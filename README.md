# IS QR — مولّد رموز QR مجاني

مولّد رموز QR عربي مجاني بالكامل، يعمل داخل المتصفح بدون تسجيل ولا رسوم.

## المميزات

- **5 أنواع محتوى:** رابط، نص، واي فاي، بريد إلكتروني، هاتف
- **6 تصاميم جاهزة:** كلاسيكي، ناعم، دائري، أزرق، بنفسجي، كلاسي
- **شعار مخصص:** ارفع شعارك (PNG / JPG / SVG / WEBP) حتى 2 ميجا
- **نص أسفل الرمز:** مع 4 أنماط خط (عادي، عريض، تقني، pill)
- **تحميل PNG و SVG** بدقة 512 / 1024 / 2048 بكسل
- **تحذير تباين تلقائي** لو لون الرمز ضعيف على الخلفية
- **يعمل محليًا** — البيانات لا تُرسل لأي خادم

## التقنيات

| التقنية | الاستخدام |
|---------|-----------|
| HTML5 / CSS3 | الواجهة |
| JavaScript (Vanilla) | المنطق |
| [qr-code-styling](https://github.com/kozakdenys/qr-code-styling) | توليد وتنسيق QR |
| [AOS](https://michalsnik.github.io/aos/) | أنيميشن السكرول |
| Google Fonts (Tajawal, Space Grotesk) | الخطوط |

## التشغيل

افتح `index.html` مباشرة في المتصفح أو استخدم Live Server:

```bash
npx serve .
```
