# IS QR — مولّد رموز QR مجاني

**أنشئ رمز QR الخاص بك، خصّص تصميمه، وحمّله مجانًا.**

IS QR أداة عربية مجانية لإنشاء رموز QR وتخصيصها بسهولة، مباشرةً من المتصفح، دون الحاجة إلى التسجيل أو دفع أي رسوم.

## المميزات

- **5 أنواع من المحتوى:** الروابط، النصوص، شبكات Wi-Fi، البريد الإلكتروني، وأرقام الهواتف.
- **6 تصاميم جاهزة:** الكلاسيكي، الناعم، الدائري، الأزرق، البنفسجي، وكلاسي.
- **إضافة شعار مخصص:** ارفع شعارك بصيغ PNG أو JPG أو SVG أو WEBP، بحجم يصل إلى 2 ميجابايت.
- **تخصيص النص أسفل الرمز:** اختر من بين 4 أنماط مختلفة تناسب تصميمك.
- **تحميل بجودة عالية:** صدّر رموز QR بصيغتي PNG وSVG، وبأبعاد 512 أو 1024 أو 2048 بكسل.
- **فحص تلقائي للتباين:** تنبيه عند انخفاض التباين بين لون الرمز والخلفية، مما قد يؤثر على سهولة المسح.
- **الخصوصية أولًا:** تتم معالجة البيانات داخل المتصفح دون إرسال محتوى QR إلى خادم، وفقًا لطريقة عمل التطبيق.

## التقنيات المستخدمة

| التقنية | الاستخدام |
|---|---|
| HTML5 وCSS3 | بناء الواجهة وتنسيقها |
| JavaScript (Vanilla) | تنفيذ المنطق والتفاعلات |
| [QR Code Styling](https://github.com/kozakdenys/qr-code-styling) | إنشاء رموز QR وتخصيص مظهرها |
| [AOS](https://michalsnik.github.io/aos/) | إضافة تأثيرات الحركة أثناء التمرير |
| Google Fonts | استخدام خطي Tajawal وSpace Grotesk |

## التشغيل محليًا

يمكنك تشغيل المشروع مباشرةً بفتح ملف `index.html` في المتصفح، أو باستخدام Live Server.

كما يمكنك تشغيل خادم محلي باستخدام الأمر التالي:

```bash
npx serve .
```
